# Тренажёр шахматных дебютов

Небольшая программа в браузере: выбираете дебют, играете за свою сторону, а соперник отвечает по теории. Каждый ход сопровождается коротким комментарием. Работает без интернета и без установки.

## Запуск

Откройте файл `index.html` двойным кликом (подойдёт любой современный браузер). Все файлы должны лежать в одной папке.

```
chess-trainer/
├── index.html    — страница
├── style.css     — оформление
├── openings.js   — база дебютов (сюда добавляются новые)
├── app.js        — логика тренажёра
├── check.js      — проверка базы дебютов: формат и геометрия ходов (необязательно)
├── check.py      — строгая проверка легальности и SAN (необязательно)
└── sounds/
    ├── Move.mp3     — звук хода
    └── Capture.mp3  — звук взятия
```

Шрифты подгружаются из интернета. Если сети нет, подставятся обычные шрифты, на работу это не влияет.

## Как пользоваться

1. На главном экране выберите дебют.
2. Выберите вариант (или «Случайный вариант») и нажмите «Начать».
3. Делайте ходы за свою сторону. Соперник отвечает сам и в каждой развилке выбирает случайную ветку.
4. Если ход неверный, клетка мигнёт красным, и можно попробовать снова.
5. Когда вариант закончится, появится сообщение «Вариант пройден!» и общая идея варианта.

**Управление**
- Ход: перетащите фигуру мышкой или пальцем либо кликните по фигуре, а затем по клетке.
- **Подсказка** подсвечивает фигуру, которой нужно ходить.
- **Режим обучения** (галочка) постоянно подсвечивает правильный ход. Для проверки знаний его лучше выключить.
- **Стрелки и кружки**: правая кнопка мыши. Протяните от клетки к клетке для стрелки или кликните по клетке для кружка. Повторное действие убирает рисунок. С Shift рисунок красный, с Ctrl синий, с Alt жёлтый. Левый клик по доске очищает всё.
- **← Все дебюты** возвращает к выбору дебюта.

## Прогресс

Количество пройденных вариантов и ошибок хранится в самом браузере (localStorage). Если очистить данные сайта или открыть тренажёр в другом браузере, счётчики начнутся заново.

## Звуки

Звуки лежат в папке `sounds/`. Чтобы заменить их, положите свои файлы с теми же именами (`Move.mp3`, `Capture.mp3`). При ошибочном ходе звука нет.

## Как добавить новый дебют

1. Сделайте копию `openings.js`.
2. Добавьте новый блок в массив `OPENINGS`. Формат подробно описан в комментарии в начале этого файла. Новые дебюты удобно писать с помощью ИИ: дайте ему содержимое `openings.js`, название дебюта и сторону, за которую играете, и попросите добавить блок в том же формате.
3. Проверьте базу командой `node check.js` (нужен установленный Node.js). Если выведется «✓ Всё в порядке», можно пользоваться. Если выведутся ошибки, в них указаны дебют, ветка и ход, где проблема.
   Для строгой проверки легальности ходов и точности SAN есть ещё `check.py`: сначала `pip install chess`, затем `python3 check.py`. Он замечает ходы, невозможные из-за связки или шаха, и неверные подписи вроде `Nd2` вместо `Nbd2`.
4. Обновите страницу в браузере.

Менять `app.js`, `style.css` и `index.html` для этого не нужно.

## Если что-то не работает

- **Страница пустая или нет карточек дебютов.** Скорее всего, в `openings.js` осталась синтаксическая ошибка (чаще всего забытая запятая или кавычка). Верните копию файла или запустите `node check.js`.
- **Нет звука.** Проверьте, что в папке `sounds/` лежат `Move.mp3` и `Capture.mp3` с точными именами, и что вы кликнули по странице хотя бы раз (браузеры не включают звук до первого действия).
- **Устаревший вид после правок.** Обновите страницу с очисткой кэша (Ctrl+F5).
